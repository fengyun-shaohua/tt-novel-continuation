# 📖 小说续写阅读器 (`novel-continuation`)

专为 **TauriTavern / SillyTavern** 打造的沉浸式太监小说与同人小说单次续写插件。

## 核心特性

1. **0 Agent · 严格单次调用 · 0 并发**：每次点击发送仅发起 1 次常规对话请求，完美兼容所有限次、防并发（Concurrency=1）的 API 渠道与酒馆破限预设。
2. **沉浸式小说阅读界面**：
   - 自动隐藏所有用户指令楼层（`is_user="true"`），原著章节与 AI 续写正文无缝相连；
   - 一键隐藏头像、名字、时间戳与聊天气泡框，呈现起点/微信读书式连续书页排版。
3. **Pagekin（书童）式时间线防剧透组装**：
   - 导入百万字 `.txt` / `.md` 自动分章存入 TauriTavern 扩展存储，并将断更前最后 N 章直接铺入当前聊天楼层；
   - 支持从目录任意章节点击 **「✂️ 从此重续」** 截断毒点剧情，本地 CJK 中文分词检索自动屏蔽截断章之后的全部原著内容。
4. **单次顺带产出总结、世界书与伏笔更新（0 额外 API 调用）**：
   - 正文末尾顺带产出 `<novel_state>` 标签块，前端收到后自动无痕剥离，后台自动更新章节摘要、人物状态时间线、待填伏笔与酒馆原生 World Info 世界书。
5. **同人小说补充设定库挂载**：
   - 支持挂载 `.json`（酒馆世界书）、`.jsonl`、`.md`、`.txt` 原作设定资料库，内置「当前状态 > 同人已写前文 > 补充原作设定库」三级蝴蝶效应保护。

## 手机端 / 桌面端通过 GitHub 地址安装

在 TauriTavern 中打开 **扩展（Extensions） → 安装扩展（Install Extension）**，填入本插件的 GitHub 仓库地址即可一键安装与更新。
